JEditor 繁體中文使用文件
========================

.. image:: image/JEditor.png
   :alt: JEditor 截圖
   :align: center

**JEditor** 是一款以 Python 和 PySide6（Qt for Python）打造的現代化、輕量級且可擴充的程式碼編輯器。
它是原版 JEditor 的完全重寫版本，效能提升 **10 倍**，同時提供更豐富的功能集。
