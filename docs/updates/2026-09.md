## U-20260923-06 · 2026-09-23 · A save that cannot be encoded no longer empties the file · #fix #files

Examples: a Big5 or cp950 tab holding a character the encoding lacks, such as "€", or an encoding name Python does not know. Reproduced: `size after: 0`.
